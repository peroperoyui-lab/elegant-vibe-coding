# 前端设计实验室

[返回手册](../../README.md) · [设计系统章节](../../docs/frontend/02-design-system.md)

直接用浏览器打开 [index.html](index.html)。与 [tokens.css](tokens.css) 放在同一目录即可，无须安装依赖、注册账户或配置模型。

## 可以体验什么

- 材料选择、关键词过滤和无结果状态。
- 浅色/深色主题，与舒适/紧凑密度的独立组合。
- 中文长标题、中英混排与长路径的换行。
- 本地模拟任务的成功、取消请求、取消确认与失败。
- 原生模态说明、Escape 关闭、焦点返回与键盘焦点环。
- 窄窗口的单列重排。

所有内容均为原创教学数据，任务由本地计时器模拟，不连接外部服务，不读写用户文件；刷新后恢复初始状态。演示中的颜色、比例和品牌图形是手册的教学方案，并非任何现有产品的正式设计基线。

## 建议观察顺序

先用默认状态阅读一份材料，再切换密度与主题；接着选择长标题材料，缩窄窗口；最后分别运行成功、取消和失败路径。试着只用键盘完成一次操作。

真实应用还需要接入实际数据、运行标识、持久化和后端状态协议，并验证目标浏览器/WebView、中文字体、系统缩放及辅助技术。本示例提供设计语言与前端状态实践的起点。
