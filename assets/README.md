# 原创图解导览

[返回目录](../README.md)

以下 SVG 可以缩放、单独打开，也可以在矢量工具中修改。它们是教学图，示例视觉与状态设计均由本手册原创编排。

| 图 | 用途 | 适合与模型讨论的问题 |
|---|---|---|
| [封面](cover.svg) | 手册视觉方向 | 为什么选用纸白、墨色、绿色和清楚的排版层级 |
| [协作闭环](workflow-loop.svg) | 任务、实现与证据 | 这次任务缺少哪一段证据 |
| [工作台布局](workstation-anatomy.svg) | 信息架构与密度 | 当前界面的主要任务和上下文怎样分配 |
| [设计前后对照](design-before-after.svg) | 同一内容的层级调整 | 哪些元素争夺注意力，怎样建立一个主动作 |
| [后端请求追踪](request-review.svg) | 从入口到结果的审查 | 失败发生在哪层，状态和副作用怎样变化 |
| [任务状态](task-states.svg) | 取消与提交的竞争 | 哪个状态是请求，哪个状态是已确认结果 |
| [设计 tokens](design-tokens.svg) | 原始值、语义与组件 | 主题变化怎样通过语义映射传到组件 |

图中配色与数值是教学选择。规范要求见正文及其来源。图内提供标题与描述，正文也解释主要含义。

维护者可用 `python3 scripts/draw_figures.py` 重新生成全部 SVG；脚本仅使用 Python 标准库。
