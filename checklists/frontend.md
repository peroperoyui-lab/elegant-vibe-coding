# 前端快速验收

[返回目录](../README.md) · [详细方法](../docs/frontend/04-design-critique.md)

按本次改动选择相关项目；每项后面填证据。规范数值和例外见[交互与可访问性](../docs/frontend/03-interaction-accessibility.md)。

- [ ] 用户进入页面后，能识别当前对象与主要动作。
- [ ] 标题、正文、辅助信息的层级清楚；同类组件使用同类样式。
- [ ] 颜色、字号、间距和图标沿用现有设计系统。
- [ ] 列表密度与阅读区舒适度分别处理；长中文、英文、数字均可读。
- [ ] 本次可达的空白、加载、成功和错误状态都有明确表达。
- [ ] 键盘可完成核心任务，焦点可见且去向合理。
- [ ] 状态由文字/形状等共同表达；对比度经过实际测量。
- [ ] 窄屏与缩放后主要操作仍可用，表格溢出有可理解的处理方式。
- [ ] 连续操作、重复点击与中途取消具有一致的反馈。
- [ ] 动态效果服务于理解，减少动态效果的偏好得到适当支持。
- [ ] 视觉对比使用相同视口、缩放、主题与数据。
- [ ] 截图之外，实际执行过本次核心用户路径。
