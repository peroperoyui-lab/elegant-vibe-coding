# 后端快速审查

[返回目录](../README.md) · [5 / 15 / 30 分钟方法](../docs/backend/02-review-in-30-minutes.md)

从本次用户路径出发。公网服务、协作系统和个人本地工具的边界需求分别确定。

- [ ] 实际入口、输入、返回与错误语义清楚。
- [ ] 参数在信任边界处理，业务规则在相应服务中执行。
- [ ] 成功状态对应真实结果，保存后可按需读取与恢复。
- [ ] 重复请求、重试与并发写入的语义已考虑相关场景。
- [ ] 外部调用拥有适当的截止时间与失败处理；重试有幂等前提。
- [ ] 取消请求、连接断开和任务最终状态区分清楚。
- [ ] 数据迁移沿项目机制执行；涉及真实数据时有恢复依据。
- [ ] 文件与数据库等不同资源的中间状态可解释。
- [ ] 模型与工具的实际配置有消费者；输出能追踪到对应运行。
- [ ] 日志足以定位本次问题，并遵守项目的数据内容约定。
- [ ] 发现包含位置、触发条件、影响和证据；疑点单列。
- [ ] 验证针对用户行为与实际风险，报告中注明环境及未覆盖部分。
