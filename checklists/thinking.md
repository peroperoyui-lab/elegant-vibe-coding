# 思考与提问检查：准备好进入下一步了吗

[返回目录](../README.md) · [提问的思想](../docs/workflow/05-thinking-and-questioning.md) · [提问画布](../templates/QUESTION-CANVAS.md)

按当前阶段选几项使用。小改动只需要与风险相称的检查；这份清单用于推进决定。

## 开始实现前

- [ ] 目标描述了具体用户情境与希望取得的进展。
- [ ] 会改变实现的模糊词已有例子与反例。
- [ ] 事实、假设、偏好和约束分别记录，关键事实有来源。
- [ ] 所选方法解决当前卡点；需要互补方法时，其用途明确。
- [ ] 选定方案保留了必要条件，并说明接受的代价。

## 进入验证前

- [ ] 成功、失败、重复请求和相关状态边界已有约定。
- [ ] 重要推断有能支持或削弱它的观察。
- [ ] 实验说明环境、变量、对照、记录与停止条件。
- [ ] 操作权限、数据保护、费用和外部影响处于授权范围内。

## 交付或继续探索

- [ ] 说明了已执行检查、实际结果和未覆盖范围。
- [ ] 代码恢复、数据恢复和外部副作用分别考虑。
- [ ] 重要风险已转成设计、测试或恢复动作。
- [ ] 结论已进入任务说明、ADR、验收或交接的恰当位置。
- [ ] 已有一项清楚、安全、可验证的小动作，可以继续执行。

如果最后一项已经明确，先用行动获取新信息。仍需讨论时，挑出最可能改变方案的一个问题即可。
